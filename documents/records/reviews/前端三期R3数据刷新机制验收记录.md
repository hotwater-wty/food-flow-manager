# 前端三期 R3 数据刷新机制验收记录

> 验收日期:2026-08-28
> 切片:P3-R3 数据刷新机制(工作台轮询 + 变更后刷新 + 聚焦刷新),计划见 [`planning/frontend-phase3-plan.md`](../../planning/frontend-phase3-plan.md)

## 改动清单

| 文件 | 改动 |
| --- | --- |
| `frontend/src/composables/use-autoRefresh.ts`(新增) | 自动刷新组合式函数:20 秒定时轮询(`AUTO_REFRESH_INTERVAL_MS` 集中定义)、`document.hidden` 时跳过、`visibilitychange`/`focus` 触发即时刷新、2 秒节流防双触发、`polling: false` 模式供顾客端只用聚焦刷新、卸载时清理定时器与监听 |
| `frontend/src/composables/use-pagedList.ts` | `load` 支持 `{ silent?: boolean }`:静默加载不点亮加载遮罩,失败仅 `console.warn` 保留当前数据(弱网/后端未启动时不刷屏) |
| `AdminOrderWorkbenchView.vue` | `load` 支持静默模式;接入 `useAutoRefresh`;工具栏新增"每 20 秒自动刷新"开关(`el-switch` 绑定) |
| `AdminSessionWorkbenchView.vue` | 同上(复用 `usePagedList` 的静默 load) |
| `CustomerOrdersView.vue` / `CustomerReservationsView.vue` | `loadOrders`/`loadReservations` 支持静默模式;接入 `useAutoRefresh(load, { polling: false })`——顾客端不轮询,聚焦/恢复可见时静默刷新 |

## 实现要点

- 三种触发(轮询、可见性恢复、窗口聚焦)统一走调用方的 `load({ silent: true })`,刷新不打扰当前操作(不闪加载遮罩、不覆盖已有错误提示)。
- 变更后刷新审计:管理端五个资料页与两个工作台的所有写操作成功后均 `await load()`;顾客端取消预约/到店开台后重新拉取列表——此前已覆盖,本片未发现遗漏点。
