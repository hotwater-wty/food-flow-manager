## 二、命令级验收

- `npx -y pnpm@11.19.0 add element-plus @element-plus/icons-vue` → 安装成功(11s)。
- `./node_modules/.bin/vue-tsc --noEmit` → 退出码 0。
- `./node_modules/.bin/vite build` → 构建成功;主包 1,007KB(gzip 322KB),系全量引入 EP 的预期代价,按计划优化后置(有 chunk 体积警告,无错误)。
- curl 验证后端链路:店长登录、`GET /api/admin/orders` 分页结构正常。

## 三、浏览器验收(1440x900 与 390x844)

1. 店长登录进入 `/admin/orders`,EP 表格六列(订单编号/桌位/下单时间/状态/金额/操作)渲染正常,状态以 ElTag 呈现(已完成=绿、进行中=黄、已下单=主色),下单时间 ISO 的 `T` 已替换为空格;
2. 中文语言包生效:分页显示"共 2 条",弹窗按钮为中文;
3. 主题桥接生效:组件主色为陶土橙(选中页码高亮、链接按钮),非 EP 默认蓝;
4. 状态筛选:下拉六项(全部状态+五种状态),选"已下单"得到空状态 ElEmpty("当前没有订单","共 0 条"),切回"全部状态"数据恢复;
5. 详情抽屉:ElDrawer 内 ElDescriptions(桌位/下单时间/订单金额)+ 菜品明细表 + 备注列表,新订单备注"自动验收菜:R2验收备注"正确呈现;
6. 状态推进链(真实数据):顾客端 API 开台+下单造一笔"已下单"订单 → 工作台依次点击"开始制作"→"标记已上齐"→"完成订单",前两步直接推进并出现 ElMessage 成功提示,终态弹出 ElMessageBox.confirm(文案含订单号与终态警示),确认后订单转"已完成";
7. 写操作锁:推进请求期间按钮进入 loading 且其余推进按钮禁用;
8. 移动 390 视口:横向菜单、顶栏员工信息、筛选/刷新按钮正常;表格可横向滚动,操作列 fixed=right 固定可见,无重叠。
9. 验收后清理:`POST /api/admin/sessions/3/close` 关闭验收会话,桌位 Z99 恢复空闲。

- 会话工作台与资料维护页仍是首版手写样式,R3 用同一套 EP 模式改造并拆分资料维护。

- 主包体积优化(EP 按需引入/分包)未纳入本阶段,留作可选任务。
