# 视觉设计与组件规则

> 状态：本节 1-4 为设计规则（仍然有效），第 5 节记录二期落地后的实现事实。

## 1. 共同令牌

- 品牌强调色：低饱和红橙色 `#C85A3F`。
- 页面背景：顾客端暖白 `#FAF8F4`，商户端浅灰 `#F5F6F8`。
- 正文：`#252525`；次要文本：`#6B7280`；边框：`#E5E7EB`。
- 字体优先系统中文字体，字重只使用 400、500、600、700。
- 统一间距基线 4px；常用间距 12、16、24、32px。
- 卡片和弹层圆角不超过 8px。

## 2. 顾客端

移动端餐饮消费感：菜品图片、价格和数量是主要信息；使用大触控区域、底部固定购物车入口和明确的当前桌位/会话状态。页面不使用营销型大 Hero，不用渐变球或装饰性背景。

## 3. 商户端

工作台感：左侧导航、顶部员工信息、内容区筛选与表格、详情抽屉。强调信息密度、可扫描性和状态操作，不使用多层卡片套卡片。

## 4. 组件规则

- 顾客端表单、Toast、Tabs、Stepper 使用 Vant；商户端表格、分页、Dialog、Drawer、Tag 使用 Element Plus。
- 图标按钮必须有 tooltip 或 aria-label；有明确文字命令时使用图标加文字。
- 状态始终同时显示颜色和文字。
- 表单提交按钮必须有 loading、禁用和失败恢复状态。
- 图片加载失败显示占位，不让布局跳动。
- 390x844 和 1440x900 都要检查文字溢出和固定元素遮挡。

## 5. 落地现状(2026-08-27 二期收口)

上述规则已在二期落地，实现位置与关键事实如下：

| 规则 | 落地方式 |
| --- | --- |
| 令牌 | [`frontend/src/styles/tokens.css`](../../frontend/src/styles/tokens.css) 集中定义色彩/间距/圆角 CSS 变量;`style.css` 全量消费令牌,不再出现裸色值 |
| 组件库桥接 | `tokens.css` 内含 Element Plus(`--el-color-primary` 系)与 Vant(`--van-primary-color` 等)主题桥接段,把陶土橙映射进两个组件库 |
| 商户端布局 | `AdminLayout.vue`:左侧两级菜单树(经营工作台/资料维护)+顶栏页名/员工姓名/角色 Tag/登出,窄屏折叠横向菜单 |
| 顾客端布局 | `CustomerLayout.vue`:顶栏品牌+账户入口、底部 VanTabbar 四项导航,高亮由当前路由推导 |
| 表单提交 loading | 各表单按钮均有 submitting 状态与失败恢复(Element Plus / Vant 原生 loading 属性) |
| 图片占位 | ElImage 与 VanImage 的 error 插槽显示"无图"占位 |
| 原生弹窗替换 | 全部破坏性确认走 ElMessageBox / showConfirmDialog,无残留 window.confirm |
| 已知取舍 | Element Plus 与 Vant 均为全量引入,主包 gzip 约 350KB;体积优化按计划后置 |
