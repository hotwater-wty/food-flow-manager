# AI 协作与验收规则

## 1. 任务模板

每次交给 AI 的任务必须写清：

```text
背景：当前用户故事和后端接口。
本次唯一目标：只完成一个切片。
允许修改：明确文件或目录。
禁止修改：无关模块、后端核心规则、未授权依赖。
已有契约：请求路径、参数、响应、权限。
验收：浏览器操作路径、失败场景、检查命令。
交付：修改文件、命令结果、截图/步骤、已知风险。
```

## 2. AI 行为约束

- 不得为了方便改接口语义或绕过权限。
- 不得用假接口替代真实接口后就宣布完成。
- 不得顺手重构无关代码或新增未经批准的依赖。
- 不得批量生成尚未评审的所有页面。
- 不得只报告“完成”，必须给出验证证据。

## 3. 人的控制点

每个切片完成后先看 diff，再运行检查，再在浏览器操作。通过后建立 Git 检查点；失败时先回滚该切片，不把失败代码继续叠加到下一任务。

## 4. 验收证据

必须包含修改文件列表、执行命令、浏览器路径、成功和失败场景、未完成事项。关键页面提供 390x844 或 1440x900 截图。
