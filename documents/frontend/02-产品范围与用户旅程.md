# 产品范围与用户旅程

## 1. 顾客旅程

```text
登录/注册
  -> 查看空闲桌位
  -> 选择人数和时间创建预约
  -> 预约到店或首页选择空闲桌位开台
  -> 查看当前开台会话
  -> 浏览启售菜品并加入前端购物车
  -> 提交堂食订单
  -> 查看订单状态和详情
```

顾客页面必须始终回答三个问题：我当前在哪张桌、当前会话是什么状态、下一步能做什么。

## 2. 商户旅程

```text
员工登录
  -> 工作台查看待处理订单
  -> 查看订单详情
  -> 已下单 -> 制作中 -> 已上齐 -> 已完成
  -> 查看等待中/用餐中会话
  -> 取消等待或清台释放桌位
```

## 3. 当前已实现

- 两类登录与注册/员工登录。
- 顾客桌位列表、预约列表、预约创建和取消。
- 首页选座开台和预约到店开台。
- 菜单、数量调整、备注、提交订单。
- 顾客订单列表和详情。
- 商户订单列表、详情和状态推进。
- 商户会话列表、取消等待和清台。
- 加载、空数据、错误、无权限、Token 过期和重复提交提示。

## 4. 当前未实现或暂停

支付、真实二维码生成、购物车后端持久化、用户资料编辑、短信、退单、改单、催单、多门店、排班、库存和复杂运营报表。二维码方案已明确暂停，不自动进入待办。

## 5. 验收故事

使用一个普通用户账号和一个店长账号，在真实后端上完成：首页选座或预约到店 -> 点餐 -> 商户接单并更新状态 -> 清台。每一步都能在浏览器中观察到状态变化，外部订单/预约变化由 SSE 触发管理端重新查询。
