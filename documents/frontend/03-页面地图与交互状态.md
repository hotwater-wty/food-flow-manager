# 页面地图与交互状态

## 1. 路由树

```text
/customer/login
/customer/register
/customer/tables
/customer/reservations/new
/customer/reservations
/customer/scan?tableId=...
/customer/session/:sessionId/menu
/customer/orders
/customer/orders/:orderId

/admin/login
/admin/dashboard
/admin/orders
/admin/orders/:orderId
/admin/sessions
/admin/reservations
```

所有顾客业务路由要求普通用户 Token；所有商户路由要求员工 Token；店长专属页面后续通过 `role === 2` 守卫。

## 2. 页面职责

- `tables`：显示空闲桌位，并提供预约和模拟扫码入口。
- `reservations/new`：人数、时间、桌位选择；提交前获取令牌。
- `scan`：读取 query 的 `tableId`，展示桌位确认并调用开台接口。
- `menu`：按分类展示启售菜品，购物车只在前端保存。
- `orders` / `orders/:id`：展示真实订单状态、菜品、金额和桌号。
- `admin/orders`：筛选、分页、详情、合法状态推进。
- `admin/sessions`：筛选、分页、取消等待、清台。

## 3. 必须覆盖的状态

| 场景 | UI 行为 |
| --- | --- |
| loading | 页面保留稳定布局，显示加载指示，不闪烁空状态 |
| 空列表 | 给出原因和下一步入口，不伪造数据 |
| 请求失败 | 展示后端 `msg`，提供重试 |
| 401/Token 过期 | 清除认证状态，回到对应登录页 |
| 403/角色不足 | 显示无权限并返回工作台 |
| 重复提交 | 按钮进入 loading，令牌只使用一次 |
| 业务冲突 | 展示后端错误，刷新相关实体状态 |
| 无当前会话 | 禁止进入点餐，提供开台/查看桌位入口 |

## 4. 状态映射

- 桌位：`0 空闲`、`1 已预约`、`2 等待中`、`3 用餐中`、`4 禁用`。
- 预约：`0 待到店`、`1 已到店`、`2 已取消`、`3 已超时`。
- 会话：`0 等待中`、`1 用餐中`、`2 已完成`、`3 已取消`。
- 订单：`1 已下单`、`2 制作中`、`3 已上齐`、`4 已完成`、`5 已取消`。
- 菜品：`0 停售`、`1 启售`、`2 售罄`。
