# 项目文档模板集

> 文档状态：当前维护规范
> 更新日期：2026-08-22

模板按当前文档职责组织，可按变更规模裁剪。模板中的“事实”“完成”和“验证”必须有源码、配置、测试或运行证据。

## 1. 当前架构事实说明

```markdown
# 主题名称

> 文档状态：当前事实
> 校准日期：yyyy-MM-dd
> 事实来源：相关源码、配置或 schema

## 当前结论
## 代码与配置落点
## 外部接口或数据结构
## 关键约束与失败模式
## 已实现能力
## 未实现候选项
## 验证方式
```

## 2. 当前阶段计划

```markdown
# 阶段名称

> 文档状态：当前计划
> 更新日期：yyyy-MM-dd

## 当前基线
## 阶段目标
## 任务与依赖
## 不纳入范围
## 风险与阻塞
## 验收标准
## 完成后的归档位置
```

计划只写尚未完成的工作；已完成内容移入基线或复盘。

## 3. 接口契约变更

```markdown
## 接口名称

- 当前实现：
- 变更原因：
- 方法与路径：
- 权限：
- 请求头：
- 路径/查询参数：
- 请求体：
- 响应类型：
- 状态与错误：
- 兼容性影响：
- 前端改动：
- 验证用例：
```

接口清单描述稳定契约；完整字段以 DTO、VO 和 OpenAPI 为准，不手写重复的大段 JSON。

## 9. 归档说明

```markdown

本文保留当时背景和推理，不代表当前实现状态。
```
