## 5. 通用错误与契约

- 业务失败为 `Result.code=0` 并可携带稳定 `errorCode`；认证缺失/无效为 HTTP 401，端侧或角色不匹配为 HTTP 403。
- 当前用户/员工归属从 JWT 上下文解析，前端不传主体 ID 作为权限依据。
- 预约和订单创建必须先获取一次性令牌；令牌过期、缺失或重复使用会失败。
- 任何新增或修改接口必须同步 DTO/VO、OpenAPI、前端契约和本清单。

## 6. 经营统计与实时通知

| 方法 | 路径 | 响应 | 权限 |
| --- | --- | --- | --- |
| GET | `/api/admin/statistics/overview` | `StatisticsOverviewVO`，今日订单/营收、状态分布、热销 TOP5 | 员工 |
| POST | `/api/admin/notifications/ticket` | 60 秒一次性 SSE ticket | 员工 |
| GET | `/api/admin/notifications/stream?ticket=...` | `text/event-stream`，ticket 消费后建立连接 | 一次性 ticket |
| POST | `/api/admin/notifications/test` | 测试事件 | 员工，仅 `dev`/`test` profile |

当前事件包括 `new-order`、`new-reservation`、`reservation-check-in`。事件只表达“数据发生变化”，客户端仍通过 REST 获取真实数据；ticket、连接和事件发布当前为单实例内存实现。
